# Python - Manejo de excepciones

Proyecto de la certificación Construyendo con IA (Google y UTEC) sobre cómo
Python detecta y gestiona errores en tiempo de ejecución.

## Objetivos de aprendizaje

- Identificar excepciones comunes: TypeError, IndexError, ZeroDivisionError, KeyError.
- Usar correctamente los bloques try y except.
- Capturar tipos de excepción específicos en lugar de excepciones amplias.
- Usar else y finally de forma apropiada.
- Lanzar excepciones explícitamente cuando sea necesario.

## Requisitos

- Ubuntu 20.04 LTS
- Python 3.8.x
- Estilo PEP 8 (pycodestyle 2.7.x)
