# Python - Funciones y modularidad

Tarea 0: islower: Función que devuelve True si un carácter es una letra minúscula, usando su valor ASCII con ord().

Tarea 1: uppercase: Función que imprime un texto convirtiendo las minúsculas en mayúsculas, usando if, ord() y chr().

Tarea 2: print_last_digit: Función que imprime y devuelve el último dígito de un número, usando abs() y el operador %.

Tarea 3: pow: Función que devuelve a elevado a la potencia b, multiplicando con un bucle for sin usar el operador **.

Tarea 4: simple_add y test_import: Archivos que muestran la diferencia entre ejecutar e importar un módulo, usando if __name__ == "__main__" para evitar que el print se ejecute al importar.

Tarea 5: add: Programa que importa la función add desde add_0.py e imprime 1 + 2 = 3, protegido con if __name__ == "__main__".

Tarea 6: calculation: Programa que importa add, sub, mul y div desde calculator_1.py e imprime las cuatro operaciones con a = 10 y b = 5.O
