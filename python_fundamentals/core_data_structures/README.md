# Python - Estructuras de datos basicas

Tarea 0: `print_list_integer.py` imprime los enteros de una lista, uno por linea, usando `:d`.

Tarea 1: `element_at.py` devuelve el elemento en la posicion idx, o None si es negativa o esta fuera de rango.

Tarea 2: `replace_in_list.py` reemplaza el elemento en la posicion idx, o devuelve la lista sin cambios si el indice no es valido.

Tarea 3: `print_matrix_integer.py` imprime una matriz de enteros, una fila por linea con los valores separados por un espacio.

Tarea 4: `add_tuple.py` suma dos tuplas posicion por posicion, completando con 0 los valores que faltan.

Tarea 5: `common_elements.py` devuelve un conjunto con los elementos comunes a dos conjuntos.
